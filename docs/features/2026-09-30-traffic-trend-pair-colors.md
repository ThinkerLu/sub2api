# 流量趋势指标对配色与差值显示

## 目的与使用

仪表盘“流量趋势”此前给五条曲线各配一种高饱和色相，四条方向曲线互不相关，肉眼难以判断哪两条本应重合。本功能按实际链路语义把四条方向曲线组织成两对：

- 请求方向：客户端上传（`ingress_body_bytes`）→ 发往上游（`upstream_request_body_bytes`）
- 响应方向：上游返回（`upstream_response_body_bytes`）→ 返回客户端（`egress_body_bytes`）

每对共用同一色相，用明度与线型区分先后两跳：深色实线表示本对起点（客户端上传、上游返回），浅色虚线表示下一跳（发往上游、返回客户端）。两条线重合时虚线被实线盖住，图上只表现为一条深色实线；两条线分离时浅色虚线露出，落差直接由两条线的间距体现。曲线之间不做填充。

总量（四条方向之和）改用中性灰、加粗线宽并保留右轴，与前四条方向曲线分离，不参与配对。

## 关键行为与限制

- 浅色主题配色：请求对深色 `#1e3a8a` / 浅色 `#3b82f6`，响应对深色 `#9a3412` / 浅色 `#f97316`，总量 `#64748b`。
- 深色主题配色：请求对 `#3b82f6` / `#7dd3fc`，响应对 `#f97316` / `#fdba74`，总量 `#e2e8f0`。
- 五条曲线保持互不相同的明度级差；同对两色只差明度与虚实，跨对靠“蓝 / 橙”两组色相分开，便于色觉异常用户区分。
- 差值是绘制结果而非过滤条件：两值相差一个字节也会显出虚线，差值越大两条线的间距越明显。前端不做阈值截断，避免掩盖真实漏计。
- 悬停提示在每个时间点列出五条曲线数值，并在存在差值时追加该指标对的差值行，格式为“两条曲线名 相差 X（Y%）”，按较大值计算百分比。
- 主题切换由 `MutationObserver` 监听 `<html>` 的 `class`，浅色/深色配色随之重绘。
- 仅改变前端呈现，不改动 API 字段、数据库结构、聚合口径或曲线取值；`GET /api/v1/admin/dashboard/snapshot-v2` 与 `GET /api/v1/admin/dashboard/trend` 的 `trend` 数据点结构不变。
- 逐点连线仍使用 `tension: 0.3` 的平滑曲线，峰值处的平滑会让相邻点差值看起来比实际略早出现，判断具体差值以悬停提示的数值为准。

## 验证

- Vitest `frontend/src/components/charts/__tests__/TrafficUsageTrend.spec.ts`：五条曲线与双轴范围、浅色与深色配色、同对色相接近且明度至少相差 0.15、总量与其余四色明度错开、浅色虚线 `borderDash` 且全部曲线 `fill: false`、主题切换重绘、悬停差值行只在存在差值时出现。
- `vue-tsc --noEmit`、`vitest run src/i18n/__tests__/localeKeyCompleteness.spec.ts`、`DashboardView.spec.ts` 需通过。
- 人工验证：用真实组件挂载浅色/深色两种主题，分别构造“两对接近”和“响应对不匹配”两组数据，确认接近时图上只呈现三条线组、不匹配时虚线分离且能一眼看出是哪一对。
